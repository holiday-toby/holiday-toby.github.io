Algorithm 05

AI 时代算法：从相似度到信息聚合

先用四个向量找出最相似的两篇文档，再用两个样本计算预测误差，最后手算一次 Attention。每一步都能把输入、运算和输出对上。

向量检索：怎样找到“最像”的文档？

假设搜索系统已经把问题和文档变成一串数。这样的数列叫向量；Embedding（嵌入表示）是把文本、图片等对象映射到向量的过程或所得表示。表示模型决定哪些差异会被保留，检索算法再按指定度量比较这些向量。下面直接给定二维向量，便于手算；真实文本的向量通常维数更高，每一维也未必对应一个能命名的语义。

查询是 q=(1,0)，文档是 A=(1,0)、B=(1,1)、C=(0,1)、D=(-1,0)。任务是返回余弦相似度最高的两篇文档，也就是 Top-K 中 K=2 的情形。余弦比较方向：点积先衡量对齐程度，再除以两个向量的长度，去掉长度的影响。

计算规则：cos(q,x) = (q·x) / (‖q‖ × ‖x‖)。其中 q·x 是对应分量相乘后求和，‖x‖ 是各分量平方和的平方根。这里 ‖q‖=1。

文档向量 x点积 q·x长度 ‖x‖相除后的结果
A=(1,0)1×1 + 0×0 = 1√(1²+0²) = 11/(1×1) = 1
B=(1,1)1×1 + 0×1 = 1√(1²+1²) = √21/√2 ≈ 0.7071
C=(0,1)1×0 + 0×1 = 010/(1×1) = 0
D=(-1,0)1×(-1) + 0×0 = −11−1/(1×1) = −1

从精确结果衡量近似检索

ANN（近似最近邻检索）通过少查一些候选或压缩表示来节省时间、内存，但可能漏掉精确结果。先保留精确扫描作为比较基线，才能知道省下的成本换来了多少遗漏。

以精确 Top-2 集合 {A,B} 为标准，若近似检索返回 {A,C}，交集只有 A，recall@2 = |{A,B}∩{A,C}|/2 = 1/2 = 0.5。若返回 {A,B}，recall@2 就是 1。这里比较集合是否找全，并不衡量返回顺序。

增大候选搜索范围往往会提高召回，也增加查询耗时。应在真实查询集上同时测召回、延迟与内存，不能只看一次查询是否命中。

为什么精确扫描能给出 Top-K？

每篇文档都按同一个公式得到分数，因此没有候选被跳过；再按分数从高到低排序，前 K 项就是这个度量下的精确结果。同分时按字符串文档 ID 升序，保证重复运行顺序一致。相似度是表示与度量的产物，不是事实正确率；检索到的文档仍可能过时、错误或与真正需求不符。

import math

def cosine_similarity(a, b):
    if not a or len(a) != len(b):
        raise ValueError("vectors must have the same positive dimension")
    norm_a = math.sqrt(sum(x*x for x in a))
    norm_b = math.sqrt(sum(x*x for x in b))
    if norm_a == 0 or norm_b == 0:
        raise ValueError("zero vectors have no cosine similarity")
    return sum(x*y for x,y in zip(a,b)) / (norm_a*norm_b)

def search(query_vec, docs, top_k=3):
    if top_k < 0:
        raise ValueError("top_k must be nonnegative")
    cosine_similarity(query_vec, query_vec)
    scored = [(cosine_similarity(query_vec, vector), doc_id)
              for doc_id,vector in docs.items()]
    return sorted(scored, key=lambda row: (-row[0],row[1]))[:top_k]

docs = {"A": [1,0], "B": [1,1], "C": [0,1], "D": [-1,0]}
print([(round(score, 4), doc_id)
       for score, doc_id in search([1,0], docs, 2)])
# [(1.0, 'A'), (0.7071, 'B')]
  • 成本：N 篇文档、每篇 d 维，全量打分 O(Nd)，完整排序 O(N log N)，总时间 O(Nd + N log N)，分数列表与排序结果占 O(N) 辅助空间；这里不含输入文档的存储。只取少量结果时可以换用堆，当前示例为了清晰保留完整排序。
  • 输入前提：向量分量为有限实数，文档 ID 为字符串，top_k 为非负整数。教学代码检查空向量、维数不符和零向量并抛出 ValueError；不额外验证类型或非有限数，也不处理极端数值导致的浮点溢出。
  • 边界：零向量没有方向，不能计算余弦；负 K 抛出 ValueError。K=0 返回空列表，K>N 返回全部文档，空文档集合返回空列表。即使 K=0，本实现仍先验证并计算所有文档分数。

表示、索引方法、检索库分别负责什么？

  • Embedding 是表示：把内容转换为可比较的数。模型和预处理应相互兼容；换一种表示，近邻也可能改变。
  • HNSW 是索引方法：构建分层近邻图，查询时沿图探索候选。它属于 ANN 方法，图连接数与搜索范围等参数影响构建成本、内存、延迟和召回，不能保证每次找到精确 Top-K。
  • Faiss 是检索库：它提供多种向量索引，包括精确扫描与 HNSW 等方法。选择 Faiss 之后还要选择具体索引与距离度量；它与 HNSW 不在同一分类层级。参见 Faiss 官方文档与索引对照表。

机器学习：先分清预测、损失和训练

线性回归用 ŷ = w×x + b 拟合数值关系。x 是输入特征，ŷ 是预测值，w 和 b 是模型参数。给定参数计算 ŷ 叫预测；拿预测与真实标签 y 比较得到的误差指标叫损失；利用数据反复调整参数以降低目标才是训练。下面只实现前两件事。

固定两个样本 (x,y)=(1,3),(2,5)。均方误差 MSE（Mean Squared Error）把每个预测误差平方后取平均：MSE = Σ(ŷ−y)² / 样本数。平方让正负误差不会抵消，较大的误差也会受到更重的惩罚。

换一组参数，损失会怎样？

w=2,b=1 时，预测分别为 2×1+1=3 和 2×2+1=5。两个误差都是 0，MSE=0。

w=1,b=0 时，预测变成 1 和 2。相对标签 3 和 5，误差是 −2 和 −3，平方后为 4 和 9，所以 MSE=(4+9)/2=6.5。

这说明第一组参数更贴合这两个样本，却不能保证对没见过的数据也表现好。判断泛化能力还需独立验证数据；实际训练可能另加正则化，限制模型过度迎合样本。

def predict_linear(x, weight, bias):
    return weight*x + bias

def mse_loss(samples, weight, bias):
    if not samples:
        raise ValueError("samples must not be empty")
    return sum((predict_linear(x,weight,bias)-y)**2 for x,y in samples) / len(samples)

samples = [(1,3), (2,5)]
print(mse_loss(samples, 2, 1))  # 0.0
print(mse_loss(samples, 1, 0))  # 6.5

这里每次单变量预测耗时 O(1)；m 个样本的损失计算耗时 O(m)，生成器只保留累计值，辅助空间 O(1)。输入是有限实数样本与参数；空样本列表抛出 ValueError，代码没有训练循环。多特征模型、参数优化和验证会带来额外成本。

几种经典模型在解决什么问题？

模型输入 → 输出关键动作与目标成本条件与限制
线性回归数值特征 → 连续数值，如面积 → 价格加权求和并加偏置；训练时通常降低平方误差预测随特征数增长；训练成本还取决于样本数与求解方法。线性形式难以直接表达复杂非线性关系，易受异常值影响。
决策树特征 → 类别或数值，如年龄、消费 → 是否流失用“某特征是否超过阈值”逐层划分，叶子给预测；选划分以减少节点内的混杂或误差预测沿一条根到叶路径，随树深增长；训练取决于样本、特征与候选阈值。树过深容易过拟合，小数据变化也可能改变分支。
XGBoost（梯度提升树）表格特征 → 多棵树合成的预测逐轮新增树，利用损失的梯度等信息修正当前目标；目标包含拟合损失与复杂度约束成本随样本、特征、树数、树深与分裂实现变化；预测需要遍历多棵树。需调学习率等参数，也不能代替防止数据泄漏与独立验证。
KMeans（K 均值聚类）数值向量与指定簇数 k → 簇分配与 k 个中心交替将点分配给最近中心、用簇内均值更新中心，降低簇内平方距离和朴素每轮逐点比较 k 个中心，成本随样本数、维数、k 和迭代次数增长。需先选 k，受尺度与初始化影响，通常收敛到局部解，簇也不自动等于真实类别。

Attention：用查询决定怎样汇总信息

Attention（注意力机制）先用查询 Q 与键 K 计算匹配分数，再把分数变成权重，最后按权重汇总值 V。K 负责打分，V 提供被汇总的内容。检索通常选择若干结果；这里保留每个值的贡献并混合成一个新向量。

只计算一个查询：q=[1,0]，两个键 k₁=[1,0]、k₂=[0,1]，对应的值为 v₁=[2,0]、v₂=[0,2]。键和查询的维数 d_k=2。这是缩放点积注意力的一次教学计算，输入向量直接给定。

为什么这些权重能用于混合？

令缩放分数为 s₁=1/√2、s₂=0。权重公式是 αᵢ=exp(sᵢ)/(exp(s₁)+exp(s₂))，得到 α₁≈0.66976155、α₂≈0.33023845。两项都是正数且相加为 1，因此输出是两个值的加权平均：α₁[2,0]+α₂[0,2]=[2α₁,2α₂]≈[1.3395,0.6605]。

代码先让每个分数减去最大分数。因为分子与分母的每项都相当于乘上同一个正数，这不改变归一化结果，却能避免直接对很大的正分数取指数。本例中指数项变成 exp(0)=1 与 exp(−1/√2)≈0.4931。不要用图上已四舍五入的权重重新计算，再期望最后一位小数完全相同。

import math

def attention(query, keys, values):
    if not query or not keys or len(keys) != len(values):
        raise ValueError("one value is required for each key")
    dk, dv = len(query), len(values[0])
    if dv == 0 or any(len(key) != dk for key in keys) or any(len(value) != dv for value in values):
        raise ValueError("inconsistent vector dimensions")
    logits = [sum(q*k for q,k in zip(query,key))/math.sqrt(dk) for key in keys]
    peak = max(logits)
    exps = [math.exp(score-peak) for score in logits]
    total = sum(exps)
    weights = [value/total for value in exps]
    output = [sum(weight*value[j] for weight,value in zip(weights,values)) for j in range(dv)]
    return weights, output

weights, output = attention([1,0], [[1,0],[0,1]], [[2,0],[0,2]])
print([round(value, 4) for value in weights])  # [0.6698, 0.3302]
print([round(value, 4) for value in output])   # [1.3395, 0.6605]
  • 输入与边界：所有分量是有限实数。查询、键列表和值向量都不能为空；键值数量相同，键与查询同维，所有值同维。违反这些形状约束抛出 ValueError。示例不额外检查非有限输入，也不保证极端数值下点积不溢出。
  • 成本：n 个键、键维数 d_k、值维数 d_v 时，单查询打分和加权共需 O(n d_k + n d_v) 时间，分数、权重与输出占 O(n + d_v) 辅助空间；不含已有 Q/K/V 的存储。
  • 适用范围：本函数只做一次单查询、单头、无掩码的前向计算。它没有学习投影、反向传播、优化器或完整模型训练步骤，不能据此推算完整 Transformer 的训练成本。

从这一次计算走到 Transformer

真实模型里的 Q、K、V 通常由输入表示分别乘以学习到的投影矩阵得到，训练会调整这些矩阵。Self-Attention（自注意力）的三者来自同一序列，让每个位置根据其他位置的信息更新表示；不同投影使“用来匹配的特征”和“要传递的内容”可以不同。位置表示补充顺序信息，否则仅靠这种点积与加权，模型无法区分位置顺序。

完整 Transformer 还组合多头注意力、前馈网络、残差连接与归一化等结构；需要自回归生成时还会用因果掩码限制可见位置。注意力权重只描述当前计算中对各个值的混合比例，不能直接作为严格的因果解释。缩放点积、投影与位置表示的原始说明可见 《Attention Is All You Need》§3.2、§3.5。

自测：把两个值对调，保持查询和键不变。权重会变吗？输出会变成什么？答案是权重不变，输出约为 [0.6605,1.3395]：匹配由 K 决定，汇总内容由 V 决定。
