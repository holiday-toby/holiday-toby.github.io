Algorithm 02

数据结构：跟着引用和队列移动

同一批数据，换一种组织方式，访问和修改的成本就会改变。这一页先用链表反转看清引用如何重连，再用图的广度优先搜索看清队列如何安排访问顺序。

链表反转：先留住后路，再改变 next

单链表的节点保存一个值和指向下一节点的 next 引用。输入是无环链表 A → B → C → D → None，我们要得到 D → C → B → A → None。这里的 A–D 是原来的四个节点；反转只修改引用，不复制节点。

用 prev 指向已经反转的前缀头，用 cur 指向尚未处理的后缀头。起初 prev=None、cur=A。每轮先把 cur.next 保存为 nxt，否则改完 cur.next，就找不到剩余链表了。图中的箭头都表示该轮结束后的 next，前缀按新的链表顺序排列。

四轮中的引用变化；每轮只重连当前节点的 next
轮次迭代前 prev / cur先保存 nxt重连迭代后 prev / cur
1None / ABA.next=NoneA / B
2A / BCB.next=AB / C
3B / CDC.next=BC / D
4C / DNoneD.next=CD / None

为什么不会丢节点？每轮开始时，prev 链是已处理部分的逆序，cur 链是未处理部分的原顺序，两部分合起来恰好包含原来的全部节点。先存 nxt，再将当前节点接到前缀前面，就把后缀的一个节点移入前缀。cur=None 时后缀为空，prev 就是完整反转链的新头 D。

class Node:
    def __init__(self, value, next=None):
        self.value = value
        self.next = next

def reverse_list(head):
    prev, cur = None, head
    while cur is not None:
        nxt = cur.next
        cur.next = prev
        prev, cur = cur, nxt
    return prev

例如先建立 d=Node("D")、c=Node("C", d)、b=Node("B", c)、a=Node("A", b)，调用 head=reverse_list(a) 后，head is d，沿 next 依次读到 D、C、B、A，且 a.next is None。这会修改原节点；旧变量 a 仍指向 A，但 A 已经成为尾节点。

成本与边界：n 个节点各处理一次，时间 O(n)，只保留三个引用，额外空间 O(1)。空链表返回 None，单节点返回该节点。输入必须是无环单链表；本函数不检测环，也不会保留原来的 next 关系。

什么时候选择链表？

  • 访问与插入：按索引找第 k 个节点通常要从头走，时间 O(k)，最坏 O(n)。已经拿到前驱节点时，在它后面插入或删除一个节点只需 O(1) 次引用修改；若还要先找前驱，总成本可能是 O(n)。需要频繁随机访问时，数组通常更直接。
  • 合并有序链表：维护两个头指针，每次取值较小的节点接到结果尾部。前提是两条输入链表已按同一规则排序；长度 m、n 的合并时间 O(m+n)。复用节点的迭代写法可用 O(1) 额外空间，但会改变原链；复制节点则需要 O(m+n) 新空间。
  • 快慢指针：一个每次走一步、另一个走两步。在无环链表中可用 O(n) 时间、O(1) 空间找中点；偶数长度时需约定返回前一个还是后一个中点。
  • 环检测：Floyd 快慢指针法比较的是节点身份，不能只比较节点值。若有环，两指针会在环内相遇；若快指针走到 None，则无环。时间 O(n)、额外空间 O(1)，其中 n 表示可达的不同节点数。检测到环后需单独处理，不能当成普通链表继续遍历。

树：先确定要支持哪种操作

树用父子关系组织层次。二叉树每个节点至多有两个孩子，但它不一定有序，也不一定平衡。以下结构解决的问题不同，不能只因为“都是树”就互相替代。

结构或操作关键动作与用途成本、前提与局限
先序 / 中序 / 后序遍历先序按根→左→右处理，适合复制层次；中序按左→根→右处理；后序按左→右→根处理，适合先汇总孩子再计算父节点。访问 n 个节点都是 O(n) 时间，递归栈 O(h)，h 是树高。中序只有在二叉搜索树上才保证得到有序序列；很深的树可能需要显式栈。
二叉搜索树（Binary Search Tree，BST）按约定让左子树键较小、右子树键较大；查找时比较键，只进入一侧。适合维护有序集合和范围查询。查找、插入、删除为 O(h)；平衡时 h=O(log n)，退化成链时可到 O(n)。重复键要有一致存储规则；普通 BST 不自动保持平衡。
二叉堆（heap）以数组存完全二叉树，最小堆让父节点不大于孩子；插入向上调整，弹出最小值后向下调整。用于优先队列、任务调度和选出最大的或最小的 K 项（Top K）。堆顶查询 O(1)，插入和弹出 O(log n)，自底向上建堆 O(n)。只保证堆顶最小，不保证整个数组有序；找任意键最坏 O(n)。
字典树（Trie）沿字符逐层走，把公共前缀共用一条路径。用于前缀判断、词典和搜索提示。若每层的孩子查询为 O(1)，插入和精确查找长度 L 的键需 O(L)。列出提示还要付出遍历和输出结果的成本；节点与孩子表可能占较大空间，不是按键数量统一算 O(log n)。

图的广度优先搜索：先入队，就先标记

图用顶点和边表示关系。广度优先搜索（Breadth-First Search，BFS）从起点出发，用先进先出的队列安排访问：先处理近的一层，再处理更远的一层。下面是无权无向图，既有环 A–B–D–C–A，也有 B、C 共享的邻居 D。

邻接表固定为 A:[B,C]、B:[A,D]、C:[A,D]、D:[B,C,E]、E:[D]。列表中的邻居顺序决定同一层的访问次序。初始化时 queue=[A]、seen={A}、order=[]；队列左侧是队头。

先出队记录 node，再按邻接顺序检查邻居；seen 中的字母仅为集合的展示顺序
出队 node本轮检查处理后 queue处理后 seen处理后 order
AB、C 首次发现：各自先标记，再入队[B,C]{A,B,C}[A]
BA 已标记；D 首次发现并入队[C,D]{A,B,C,D}[A,B]
CA、D 均已标记；D 不再次入队[D]{A,B,C,D}[A,B,C]
DB、C 已标记；E 首次发现并入队[E]{A,B,C,D,E}[A,B,C,D]
ED 已标记，无新顶点[]{A,B,C,D,E}[A,B,C,D,E]

为什么按层走？队列先进先出；距离为 k 的节点会在新发现的距离为 k+1 的节点之前出队。首次发现一个邻居时，如果有更短的路线，它就会在更早的层被发现。因此无权图的首次发现层数就是最短距离。这里 A=0，B/C=1，D=2，E=3。入队时立刻加入 seen，使环和共享邻居都不会造成重复排队。

from collections import deque

def bfs(graph, start):
    if start not in graph:
        raise ValueError("start must be a vertex")
    seen, queue, order = {start}, deque([start]), []
    while queue:
        node = queue.popleft()
        order.append(node)
        for nxt in graph[node]:
            if nxt not in seen:
                seen.add(nxt)
                queue.append(nxt)
    return order

将上面的邻接表写成字典后，bfs(graph, "A") 返回 ["A", "B", "C", "D", "E"]。返回值只是遍历顺序，并不包含距离或最短路径；需要距离时，可在首次入队时记录 dist[nxt]=dist[node]+1，需要还原路径时再记录前驱。

成本与边界：采用邻接表，且集合查询平均为 O(1) 时，每个可达顶点入队一次、每条可达邻接项检查一次，时间 O(V+E)，额外空间 O(V)（包括返回顺序）。这里 V、E 指从起点可达的顶点和边；无向边在邻接表中出现两次，不影响数量级。若改用含 N 个顶点的邻接矩阵，每次扫描 N 个候选邻居，遍历 V 个可达顶点耗时 O(VN)，最坏 O(N²)。

前提是邻接表为每个顶点都提供键，包括没有邻居的顶点；顶点可以用作集合元素。函数只访问起点可达的部分，不修改图。孤立起点返回 [start]；起点不存在（包括空图）抛出 ValueError。有向图也可使用这段代码，但只能沿列出的出边前进。

图算法怎么选？

工具问题与关键动作成本与使用条件
BFS / 深度优先搜索（Depth-First Search，DFS）BFS 用队列逐层探索，适合无权最短距离；DFS 用递归或显式栈先走深再回退，适合可达性、连通分量和搜索路径。邻接表加访问标记时都为 O(V+E) 时间、O(V) 额外空间。遍历全图要从尚未访问的顶点继续启动；DFS 首次找到的路径不保证最短。
Dijkstra 单源最短路每次取当前距离最小的候选顶点，尝试用它改进邻居的距离（松弛）。适合道路耗时等带权距离。要求边权非负。邻接表配二叉堆、每个顶点维护堆位置时为 O((V+E) log V) 时间；常见允许重复条目的堆写法为 O((V+E) log(V+E)) 上界。不能直接用于含负权边的图。
Floyd–Warshall 全点对最短路依次允许一个顶点充当中转点，更新每一对起终点的距离。适合顶点较少、需要多次查询任意两点距离的图。距离矩阵与三重循环为 O(V³) 时间、O(V²) 空间。可有负权边，但若路径可经过负权环，就没有有限最短距离；不能把矩阵结果当作正常最短路使用。
拓扑排序反复取出入度为 0 的顶点，并降低其后继入度；给任务依赖安排先后顺序。Kahn 算法采用邻接表为 O(V+E) 时间、O(V) 额外空间。完整顺序存在的前提是有向无环图（Directed Acyclic Graph，DAG）；输出不足 V 个顶点表示有环。
并查集（Disjoint Set Union，DSU）用代表元标识集合，find 查询代表元，union 合并集合；适合动态增加连接、查询无向连通性和判定新增边是否成环。初始化需 O(V) 时间；路径压缩配按秩或按大小合并后，m 次操作为 O(m α(V)) 摊还时间，空间 O(V)，α 是增长极慢的反阿克曼函数。基础并查集不支持任意删边，也不能求一般最短路或判断有向可达性。
