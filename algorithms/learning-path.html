Algorithm 06

算法学习路线

从“能跟着算”走到“能解释为什么这样做”。每一阶段用具体输入、手写状态和边界结果检查理解，再按眼前的问题选择下一步。

从哪里开始：先修关系与学习证据

开始前，先能读懂 Python 的变量、条件、循环、函数、列表和字典；知道下标从 0 开始，能用纸笔跟踪一次赋值。若还不能解释 x = nums[i] 与 nums[i] = x 的区别，先补这一步，再进入算法练习。

用结果决定下一步

  1. 先预测：不运行程序，写出这组输入的返回值与中间状态。
  2. 再对照：打开对应专题，逐步比较图、表和 Python 实现，找出第一次分歧。
  3. 换一个边界：例如空数组、空链表或缓存未命中，再解释为什么结果成立。
  4. 按缺口回看：队列顺序写错就回基础结构；递归返回后状态残留就回回溯撤销。能背出名称还不足以进入下一步。

这不是固定周数的课表。已经懂数组、当前要理解缓存的读者，可以沿下方案例理解最近最少使用缓存（Least Recently Used，LRU）；暂时用不到线段树，就等出现区间查询问题时再深入。

第一阶段：基础

先会什么：能跟踪循环中的变量变化，并区分“数组中的位置”和“节点之间的引用”。从数组与哈希表开始，再比较链表、栈、队列和树，最后用排序与二分练习有序性的作用。

练什么：用数组下标访问元素；用哈希表按键定位；画出链表的 next；用栈解释后进先出、用队列解释先进先出；沿树的父子关系访问节点。跟着基础页的快排过程分组，再在有序数组上找第一个不小于目标的位置。

怎样判断掌握：能说明数组随机访问为何方便、链表改引用前要保留什么；能对 [2,4,4,7,9] 查 4 返回下标 1，而不是任意一个 4；能解释空输入和查不到时的插入位置。比较方案时，同时说明时间、额外空间与输入前提。

练习排序与二分边界 · 跟踪链表指针与树结构

第二阶段：核心思想

先会什么：会用栈、队列和树；能读懂函数调用与返回。递归先写清“何时停止、规模怎样缩小”，再学习深度优先搜索（DFS，先沿一条分支走深）与广度优先搜索（BFS，借队列逐层扩展）。图有环时还要记录已访问节点。

练什么：手写 BFS 的入队、出队过程；用爬楼梯理解动态规划（DP）如何保存子问题结果；用互异元素的全排列练习回溯的“选择、递归、撤销”。对贪心选择，必须说明局部最优为什么能通向整体最优，不能把看起来合适当作证明。

怎样判断掌握：能从队列推出 BFS 的访问顺序；用 f(0)=1、f(1)=1 和 f(n)=f(n-1)+f(n-2) 算出 climb_stairs(5)=8；能指出回溯返回后恢复路径与使用标记的两行。遇到新题时，先定义状态或搜索范围，再选择方法。

手写 BFS 队列变化 · 练习递归、DP、贪心与回溯

第三阶段：进阶与应用

先会什么：能画出数据关系、解释一次遍历，并用时间和空间成本比较候选方案。图的基本表示与 BFS 可以在第二阶段入门，这里再学习路径、连通性和更多查询需求。

练什么：图表示关系与路径；并查集维护集合合并和连通性；前缀树（Trie）按字符路径处理前缀；堆维护极值或候选集；线段树处理区间查询与更新；位运算和状态压缩用二进制表示小规模集合。这些工具各有问题边界：并查集不直接给出路径，堆不提供全部元素的排序，状态压缩也不会消除状态数的指数增长。

怎样判断掌握：先写操作需求，再组合工具。缓存既要按键找到数据，又要维护最近使用顺序；向量检索既要计算相似度，也要选出前 K 项。能演算一次淘汰或排名，解释容量、零向量等边界，并说明教学实现与生产系统之间还缺哪些约束。

按实际方向安排优先级

方向帮助选择先练的场景，具体工具仍由输入、操作和规模决定。同一岗位可能同时用到几个阶段，也可能长期不需要某一种进阶结构。

  • 后端：先练哈希定位、缓存更新与容量边界，再按任务学习堆和图。排行榜候选可借堆维护，依赖关系可用图表示；跨节点路由再看一致性哈希。先说明一次请求读写什么，再谈平均性能和故障约束。从工程案例开始。
  • 前端：先练树、递归与 DFS/BFS，用组件树或菜单树跟踪访问；处理搜索建议时再比较字符串匹配与前缀结构。界面更新还受渲染和状态管理影响，学会遍历并不等于掌握全部差异比较策略。先跟踪树与遍历。
  • AI：先补向量、点积、长度和基础概率，再手算检索排名、线性预测误差与注意力权重。扩大到大量文档时，再比较精确检索的成本和近似检索的召回损失；先能解释小输入，才容易判断库返回的结果。从四个文档的检索开始。
  • 游戏开发：先练图、队列与搜索，在无权地图上解释 BFS 的最少步数；有不同移动成本时再研究相应最短路与 A* 搜索及其启发条件。碰撞候选多时再引入空间分区，并核对每帧更新成本和漏检边界。先核对 BFS 的适用条件。
