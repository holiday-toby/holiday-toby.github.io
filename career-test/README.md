# 性格偏好自测

本站原创场景题用于自我观察和职业探索，未经标准化信效度验证，不是官方 MBTI 测评。题量增加和计分修正不代表已经证明准确率提高。

## 题库与流程

- 共 64 题，每组 8 题，可返回修改，当前组完成后继续。
- 前 48 题：EI、SN、TF、JP 各 12 题，交错覆盖生活、学习与合作场景。
- 后 16 题：AO、CH 各 8 题，作为独立扩展维度。
- 每轴两种左右方向各半，避免固定位置总是对应同一字母。
- 选择按近半年多数情况下的自然反应理解。刷新页面会清空答案，当前不存储或上传作答。

扩展维度采用本站定义：A 果断笃定 / O 审慎易纠结，C 克制表达 / H 热情表达。它们不属于官方 MBTI 四维，也不是荣格功能维度。C 不代表冷漠，H 不代表外向。

## 计分与结果

五级作答值为 −2、−1、0、1、2；0 是有效中立答案，未答或无效值会阻止生成结果。题目的 `rightLetter` 与该轴规范右侧一致时累加原值，方向相反时取负值。

每轴最大分 = 题数 × 2。右侧倾向分 = `(总分 + 最大分) / (2 × 最大分) × 100`，四舍五入；左侧 = 100 − 右侧。数值是作答倾向分，不是准确率、概率或能力。

- 总分为 0：显示 X（未分化），不向任何一侧补字母。
- `abs(总分) / 最大分 < 0.25`：提示接近中间。25% 是展示用的启发式阈值，未经常模校准。
- 基础临界轴的两侧组成可参考候选类型，不排序、不声称匹配概率。
- 基础含 X 时不套用某一个类型的职业画像；给出通用探索建议。
- AO、CH 各自独立计分，例如 `INFP-A-H`；平分后缀为 X，临界后缀明确说明仅为略偏。
- 修改答案立即清除旧结果；复制包含六维倾向、临界提示与测试性质说明。

## 文件和验证

- `mbti-data.js`：原创题库、量表、维度定义、16 型职业建议。
- `mbti-scoring.js`：可独立测试的纯计分函数。
- `mbti.js`：分页、进度、缺题提示、结果渲染与复制。
- `mbti.test.cjs`：Node 内置测试，无额外依赖。

在仓库根目录运行：

```sh
node --test career-test/mbti.test.cjs
node --check career-test/mbti-data.js
node --check career-test/mbti-scoring.js
node --check career-test/mbti.js
bundle exec jekyll build
```

浏览器检查应覆盖：未答定位、8 组往返、答案保留、最后两组扩展题、全中立、正常类型、临界结果、修改后旧结果失效、重置、复制成功与失败、320px/375px 窄屏。

## 后续优化方向

1. 用小规模访谈检查题目是否易懂、是否混入能力或社会期待，优先改写有歧义的题。
2. 在知情同意下收集匿名试测数据，检查同一维度题目的一致性、区分度与场景覆盖；减少重复题。
3. 通过间隔复测观察稳定性，特别关注临界轴；有数据后再评估阈值和题目权重。
4. 将职业探索补充为兴趣、技能和工作价值观自评，避免只由四字母推出职业结论。

参考：[Myers & Briggs Foundation 对四组偏好及结果的说明](https://www.myersbriggs.org/my-mbti-personality-type/my-mbti-results/home.htm)。官方测评的验证结果不能套用于本站原创题库。
